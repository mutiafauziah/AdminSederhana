# AdminSederhana
Membuat halaman admin sederhana dengan menggunakan template backstrap dengan struktur CRUD (Create, Read, Update, dan Delete) . Dimana memuat data karyawan yang telah diabsen dengan fitur update, delete, sort by dan pagination. dalam halaman input data absensi memuat nama, alamat, jenis kelamin, tanggal absen, jam masuk dan jam keluar
